# Brand name research: Tabloom + 15 alternatives

Research date: 2026-11-05. All facts accessed 2026-11-05 unless noted.
Labels: [Verified] = seen at source; [Inference] = analytical reasoning; [Hypothesis] = untested.

**Not legal advice.** Nothing here says a name is legally available or free to use. No trademark office search
was run (USPTO / EUIPO / WIPO Global Brand Database were not queried in this session). Every name is
**"trademark search pending"** until a qualified clearance search is done. Names containing "Chrome" or
"Google" were excluded on purpose.

## Method

| Check | How | Caveat |
|---|---|---|
| .com status | `whois NAME.com` (Verisign) + `dig +short NS NAME.com` | "Registered" ≠ in use; "No match" ≠ purchasable (could be reserved, premium, or registered minutes later). Parked/marketplace NS (afternic, hugedomains, squadhelp) suggests for sale at a premium. |
| .app status | Google Registry RDAP `https://pubapi.registry.google/rdap/domain/NAME.app` (plain `whois` does not return .app data) | HTTP 404 = no registration record at query time, which is not the same as purchasable. 200 = registered (registration date shown). |
| GitHub | `https://api.github.com/search/repositories?q=NAME` and `/search/users?q=NAME` (unauthenticated) | Counts are fuzzy-match totals; top 3 shown with stars. |
| Web / products | WebSearch (US results) for the exact name + "app" | Absence in one search ≠ no product exists. |
| Trademark | Not performed | Pending. Not legal advice. |
| Pronunciation / meanings | Reasoning only | [Inference]; no native-speaker check done. |

## Codename check: "ProfileDock" (internal doc codename) — collision confirmed, do not ship under it

- profiledock.com: registered 2024-07-23 (Spaceship), NS squadhelp; the site 302-redirects to `https://www.atom.com/name/ProfileDock` (a domain marketplace listing). [Verified, whois + curl]
- profiledock.app: RDAP 404 (no record). [Verified]
- GitHub has three unrelated same-name projects, two in our exact space: [Verified, GitHub API]
  - `nothingness-dev/ProfileDock` (created 2026-08-14): Python CLI for isolated, persistent Chromium profiles.
  - `yolucorp/ProfileDock-releases`: release feed, v1.0.5 published 2026-08-20; Portuguese release notes mention sessions, sync and a plan indicator, which suggests a commercial session/profile product. [Verified releases; "commercial" is Inference]
  - `breukr/profiledock` (created 2026-09-12): native macOS companion for ChatGPT/Codex profiles with optional custom Dock icons.
- A web search for "ProfileDock" did not surface a product website, so the size of these products is unknown.
- Conclusion [Inference]: the codename overlaps with at least one Chromium-profile tool and one macOS profile/Dock-icon tool. Keep it as an internal codename only.

## Per-name notes

**1. Tabloom (current working name)**
- Collisions [Verified]: Chrome Web Store "Tabloom: Tab & Session Manager" (v1.4.0, updated 2026-07-21, site tabloom.net) https://chromewebstore.google.com/detail/dgbmhaohiamgejjdndgfmbdhfkljdbci ; "TabLoom: Visual Tab Group Mindmap" https://chromewebstore.google.com/detail/bahegaolgkmgnjnppnlgkfedbfnnfila ; a Notion privacy policy for a third "Tabloom" new-tab extension https://diagnostic-path-89c.notion.site/Privacy-Policy-for-Tabloom-3434a0519b438031be10c3cb6e0b14b7
- tabloom.com shows "Tabloom.com is for sale | HugeDomains" [Verified, curl]. tabloom.app registered 2025-04-20.
- Search ambiguity: **high**. Same word, same browser niche, two live Chrome extensions.
- Fit [Inference]: "Tab" suggests tab management, but the product is about profiles and app identity, so the name points users to the wrong problem.
- Pronunciation: easy (TAB-loom). No problematic meanings found [Inference].
- Trademark search pending, not legal advice. Recommendation: **drop**.

**2. Hatrack**: "wearing many hats" metaphor for work/personal/client identities; memorable. hatrack.com is Orson Scott Card's long-running Hatrack River site (https://alt.org/nethack/mirror/www.hatrack.com, archived). Hatrack LLC software firm listed at https://village.ai/company/hatrack-llc. Both .com and .app taken, so you would need a modified domain (e.g. gethatrack). Medium search ambiguity. Trademark search pending.

**3. Twinly**: Twinly AI matching app on AlternativeTo (https://alternativeto.net/software/twinly/about/); Twinr no-code builder causes confusion. Both domains taken. "Twin" implies copies, not separate identities [Inference]. Trademark search pending.

**4. Splitdock**: describes the product (split one browser into many Dock apps). .app no record; .com recently registered and parked at Afternic (likely for sale at premium; price not checked). Wavebox uses "Split & Dock" as a feature name (https://hub.wavebox.io/dock-split-view/). "Split" may also read as split-screen [Inference]. Easy to say. Trademark search pending.

**5. Facetab**: .app no record. "Face" may suggest facial recognition or Facebook [Inference]. Low recall of meaning. Trademark search pending.

**6. Profilo**: means "profile" in Italian; descriptive and weak as a mark [Inference]. Facebook's archived Profilo profiler (1.6k stars) dominates GitHub. profilo.com is held through a corporate brand registrar (CSC) since 1996, which suggests an established brand owner [Inference]. Trademark search pending. **Drop.**

**7. Dockling**: a Mac app named Dockling already exists (pixel pet that lives in the Dock; https://hunted.space/product/dockling). Also sounds like IBM's Docling. **Drop.**

**8. Tabsmith**: .app no record, .com taken. Same "tab" mismatch as Tabloom. Trademark search pending.

**9. Alterdock**: "alter ego" + Dock: a second self in the Dock. Cleanest result: .com whois "No match", .app no RDAP record, no GitHub user, no product found. Risks [Inference]: may be read as a Docker tool; "Alter" in German means age, or "dude" as slang (mild, not offensive). Pronunciation: AWL-ter-dock, clear in English. Trademark search pending.

**10. Masklet**: "mask" connotes hiding identity, which overlaps with anti-detect / multi-accounting browsers and could hurt trust with reviewers [Inference]. Trademark search pending.

**11. Switchling**: playful, ties to Cmd-Tab switching. .com registered 2024 (in use or held, unknown). Trademark search pending.

**12. Multiself**: .com is listed at HugeDomains (for sale). Reads like psychology or identity-disorder language; awkward [Inference]. DeepMind research repo uses the name. Trademark search pending.

**13. Roleport**: "role" + "port". .com registered Aug 2025 with a Spaceship launch page, so someone may be building on it. "Role portal" reads as HR/IAM software [Inference]. Trademark search pending.

**14. Hatbox**: generic word; .app registered 2026-07-26; 45 GitHub users. Weak distinctiveness. Trademark search pending.

**15. Personabar**: "persona" fits profiles well; both domains have no record. Collision: DNN (DotNetNuke) CMS calls its admin UI the "Persona Bar" (e.g. GitHub `ashishpd/Dnn.PersonaBar.Samples`). Different audience (web admins), still software [Inference]. "Bar" suggests a menu-bar app, which this product is not [Inference]. Trademark search pending.

**16. Tabtwin**: TabTwin Chrome extension already exists (https://chromewebstore.google.com/detail/beglldlnijpoegeadchghkhkjhjcndkg, https://www.producthunt.com/p/tabtwin) plus "Tabtwinsy". **Drop.**

## Finalists (recommendation)

1. **Alterdock**: the only candidate with no .com whois match, no .app record, no GitHub user and no product found. The "alter ego in your Dock" story explains the product in three words. Watch the Docker association.
2. **Splitdock**: most descriptive ("one browser, split into Dock apps"); .app has no record. .com is parked at a marketplace, so plan on the .app domain or a get-/use- prefix. Wavebox's "Split & Dock" feature is a nearby term, not a product name.
3. **Personabar** (or a variant like "Persona Dock", not checked): strongest meaning fit for profiles; both domains show no record. Weaker because of the DNN "Persona Bar" collision and the menu-bar connotation.

Honourable mention: **Hatrack** is the most memorable metaphor, but both domains are taken and a 1990s author site owns hatrack.com.

**Tabloom**: not recommended. It collides with at least two live Chrome tab-manager extensions using the same name, and the "tab" framing mislabels the product.
